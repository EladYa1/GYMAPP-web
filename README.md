# GYMAPP — גרסת ה-web

הריפו הזה מכיל **תוצר בנייה בלבד**, ואין לערוך אותו: הוא נדרס בכל פרסום.
הקוד יושב בריפו הפרטי `GYMAPP`, בתיקיית `Web/`.

האתר: https://eladya1.github.io/GYMAPP-web/

## למה הוא ציבורי

GitHub Pages אינו זמין מריפו פרטי בחשבון חינמי. ההפרדה הזו היא מה
שמשאירה את הקוד, ההיסטוריה והתיעוד בריפו פרטי, וחושפת כאן רק את מה
שכל מבקר באתר מקבל לדפדפן שלו בכל מקרה.

## פרסום מחדש

מתוך הריפו הפרטי:

```powershell
dotnet publish Web\GYMAPP.Web.csproj -c Release
```

ואז העתקת `Web\bin\Release\net10.0\publish\wwwroot` לכאן, עם שני
תיקונים שחייבים לקרות בכל פעם:

1. קובץ `.nojekyll` בשורש — בלעדיו Pages מריץ Jekyll, שמתעלם מתיקיות
   שמתחילות בקו תחתון, כלומר מ-`_framework`, כלומר מכל האפליקציה.
2. `<base href="/GYMAPP-web/" />` ב-`index.html` במקום `"/"` — האתר
   מוגש מתוך תת-נתיב.
